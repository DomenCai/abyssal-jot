# 复刻优化方案（Claude × Gemini 共识版）

- 日期：2026-11-24
- 目标：复刻甚至超过 `ObsidianOriginal.mp4` 的效果
- 状态：已实施（Opus 子代理实现，Codex gpt-6.2-sol 审查两轮并修复），视觉验收（G2 对比录屏与盲测）未做
- 依据：原片 92 秒（重点 00:01–00:20、00:27、00:36、00:45、00:68）与复刻录屏 `ObsidianRecord.mp4` 前 20 秒；对比素材在 `.video-review/`

## 核心判断

原版每格 = **实心底色 + 字符**，底色亮度逐格变化，像把有光照的 3D 渲染图降采样成格子：亮部浅底深字，暗部深底亮字，格子层下面还垫着一层连续的模糊体积光。复刻版的差距不在参数，在于缺了"光照"这一层：现在蒙版是平涂的 alpha 0.5，格子底色实际只有约 0.1（`src/ocean.ts` 的 `lum * (0.3 + glow * 0.25) * fade`），画面只剩稀疏字符。

Gemini 判断原版大概率是 3D 模型实时采样。共识是先走 **路线一：2.5D 带色光照 Canvas2D**；验收不达标时，只把"离屏光照渲染"这一层换成 **路线二：无依赖的轻量 3D 低模离屏渲染**，格子采样和柔光合成那一层不动。

## 方案

### 一期：质感（决定成败）

| 编号 | 内容 |
|---|---|
| A1 | 蒙版改为 96×96 的 **RGBA 带色光照离屏图**，不再用 alpha 当亮度。身体沿法线渐变（背脊高光 → 体侧 → 边缘暗），鳍更暗；水母画成**中空玻璃罩**：伞缘亮环、内部暗透、口腕核心发光 |
| A2 | 格子着色：底色 alpha ≈ `pow(lum, 0.8) × 0.85 × fade`；暗部向冷青蓝 `[20, 35, 58]` 偏移，`lum > 0.8` 时提白；字符在 `lum` 0.55–0.7 之间平滑反相（亮部深字） |
| A3 | 柔光垫层：低分辨率离屏图开双线性平滑放大，画在格子层下面。分辨率按格子定义：标准档近层每像素 2 格、远层 4 格，省电档单层 3 格，换网格密度时光晕和生物一起缩放。**不用 `ctx.filter` blur**，因为高 DPR 下开销大 |
| A4 | 水母 size `[5, 7.5]` → `[6, 8.5]`（伞盖直径约为鲨鱼体长的一半，连触手总长与鲨鱼相当；最初定的 `[11, 16]` 实测比鲨鱼大一倍，已按用户反馈改小），触手相应加长；`MASK` 72 → 176（为容纳放大后的鲨鱼：中心到尾鳍叶片末端约 0.7 体长）；水母在蒙版里向 +x 偏置，避免长触手被截断 |
| A5 | 叠一层随生物本体坐标走的低频噪声（±0.08–0.12），让同亮度区的字符有斑驳感，不随屏幕闪烁，也不破坏高光轮廓 |
| A6 | 鲨鱼俯视最宽处约为体长的 0.2（双髻鲨 0.18、尖吻鲨 0.23），胸鳍、尾鳍叶片和眼睛按体长比例绘制；新增 `ray`（蝠鲼：菱形双翼正弦扇动 + 长鞭尾）；双髻鲨增加尖吻流线型头部变体；调色板：暖金/米色给鲸鲨或大鱼，冰青/淡紫给水母 |
| B1 | 底色 `#06080c` → `#030407`；网格线 alpha 按格子档位分：8px 用 0.008、10px 用 0.012、14px 用 0.016 |
| B2 | 暗流加低频包络，成团、横向拉伸成波带，以 `.` `:` 为主，团内 alpha 上限 0.35，团外基本不画 |
| E3 | 景深：远处生物的柔光更模糊、更冷、更暗，近处更清晰、微暖、更亮 |
| F3 | `saver` 档跳过 A5 噪声和 E3 多层模糊，只画单层柔光 |
| H1 | 速度按体长定义，每帧按 `体长/秒 × size × cell` 换算成像素，切换网格密度时视觉速度不变：鲨鱼 0.13–0.17 体长/秒（鲨鱼后按用户反馈放大到 84–119 格、约原来的 3.5 倍，体长/秒同比除以 3.5，像素速度保持不变），鲸鲨 0.25–0.35，蝠鲼 0.35，水母 0.25–0.35 伞径/秒（保留"收缩推进、舒张滑行"），小鱼群约为现在的 2.5–3 倍。最终以左右对比视频为准 |
| H2 | 最大转向角速度提到约 0.8–1.2 rad/s；摆尾和搏动频率**不按倍数放大**，留在自然区间（鲨鱼约 4.5–6.5 rad/s，水母搏动约 2.0–2.6 rad/s），避免像快进；重新选目标的半径从固定 60px 改为约 1.5 秒的路程 |
| H3 | 性能档合并为两档：省电 30fps（生物 ×0.6）/ 标准 60fps，删掉 `smooth`。实施时测 `render()` 单帧耗时，超过约 8ms 就先把字符预渲染成精灵图，用 `drawImage` 代替逐格 `fillText` |
| H4 | 运动连续化：柔光层用生物的浮点坐标、不吸附格子；蒙版按亚格小数平移（`baseCol = floor(x / cell) - MASK / 2`，`translate(MASK / 2 + fracX, MASK / 2 + fracY)`）。格子仍锁在网格上，但前沿逐渐变亮、尾部逐渐变暗，不再整只一下跳一格 |

### 二期：打字手感

| 编号 | 内容 |
|---|---|
| C1 | Dither 换行彗尾改为宽度渐细的 2D 像素带：头约 12px → 尾 1px，2px 像素格，4×4 Bayer 阈值画纯白方块，头部带弧形刷头，落点迸一次小墨滴；`COMET_MS` 300–360 |
| C2 | 组字期间每次 composition 更新迸 3–4 颗小墨滴（约 60ms 节流，限制同屏上限），上屏时迸完整墨滴；墨滴 size 2–4，数量 6–10 |
| C3 | 光标颜色随预设：Dither 白，Pastel 粉 |
| D6 | 输入行高 1.75 → 1.9；`X:.. Y:..` 合并成单个约 10px 高的胶囊；离上一行太近时放到词框下方 |
| F1 | Pastel：① 合并胶囊（颜色随词轮换为可选）；② 上屏时在词组周围迸一小片柔彩 ASCII 字符（`$ % X t :`）。两种预设：③ 在 fx 画布上给刚上屏的词组叠一层圆角色块，alpha 0.16–0.22，500ms 淡出（Pastel 用当前涟漪色，Dither 用冷蓝灰；跨行只高亮最后一行）。用色块是因为 textarea 不能给局部文字上色 |
| F2 | 预设胶囊在 Dither / Pastel / **动效已关** 三档之间循环 |

### 三期：UI 与陪伴感

| 编号 | 内容 |
|---|---|
| D1 | "暂停动效"和左下提示固定上移到 `bottom: 36px`，避开 Obsidian 状态栏；加暂停/播放图标 |
| D2 | 标题 font-weight 300 → 200，加 `-webkit-font-smoothing: antialiased` |
| D3 | 下拉框 `appearance: none`，内联 SVG 绘制下拉箭头 |
| D4 | 输入卡底色 `rgba(10, 13, 20, 0.62)`，边框 alpha 0.09 → 0.11 |
| D5 | 发送按钮：输入为空时变暗，有字时点亮 |
| D7 | 状态行前加预设图标，仍保持 3 秒淡出 |
| E1 | 克制版生物回应：打字时附近一只生物极缓慢地靠近卡片外圈（有最小安全距，不进卡片后方）；换行只惊散小鱼群；保存时生物随水波向外游 |

## 验收

- 每期做完，在与原版一致的条件下录 20 秒：细格、多种混游、窗口尽量 16:9、隐藏左侧栏。剪成左右对比视频，交 Gemini 审。
- 一期结束后，新开一个无上下文的 Gemini 做 A/B 盲测：只给两段视频，不说明哪段是原版。
- 一期标准：生物有实心体积感，能一眼认出物种，亮部浅底深字，盲测中不明显输给原版。不达标时把离屏渲染换成路线二。

## 决策日志

| 条目 | 结论 | 理由 |
|---|---|---|
| A1 灰度 vs 带色光照 | 采纳 Gemini 改法：RGBA 带色 | 原版同一生物内有冷暖色相变化，单通道灰度乘单色会发平 |
| A3 blur 实现 | 采纳 Gemini 改法：低分图双线性放大 | `ctx.filter` 在高 DPR 下开销大 |
| A3 柔光分辨率 | 实施时从"主画布 1/6–1/8"改为按格子定义；Codex 第 1 轮提出按原方案改回，不采纳 | 蒙版本身 1 像素 = 1 格，按设备像素的 1/8 比一格还细，几乎起不到模糊作用；按格子定义，换网格密度时光晕和生物一起缩放 |
| 3D 路线 | 先路线一，不达标再换路线二 | 路线一零依赖、风险低；两层本来就分开，替换成本小 |
| D1 状态栏避让 | 采纳 Claude：固定 36px，不读 `.status-bar` 高度 | 读高度要监听显隐和尺寸变化，多一套状态；Gemini 同意 |
| D7 / N2 状态行常驻 | 不常驻，保持 3 秒淡出 | 原版常驻可能只是演示状态；常驻长期占视线，违背克制原则 |
| N1 右上第 3、4 控件与"试玩中英+换行" | 不还原 | "试玩"是原作者录演示用的自动打字（1080p 原片已确认），不是用户功能 |
| E2 光标微光 | 不做 | 隔着毛玻璃效果弱，还会在正文背后制造白雾 |
| E4 语义共鸣微光 | 列为后续候选，本轮不做 | 属于新的产品功能，不是视觉还原 |
| F1-1 胶囊颜色轮换 | 降为可选 | 只在 00:68 看到标签偏浅，证据弱 |
| 00:27 整屏重影 | 不还原 | 判断为视频剪辑转场，不是插件效果 |
| H 游速与卡顿（用户追加） | 必做，并入一期 | 用户要求。实测原版双髻鲨约 0.5 体长/秒，复刻约 0.09，慢 5–8 倍；"卡"是因为按格吸附加低速，约每 0.4–0.5 秒才跳一格，标准档又只有 30fps；原版 20 秒内约 1135 帧有变化，判断为 60fps |
| H2 摆尾频率 | 采纳 Gemini：不随速度按倍数放大 | 按倍数放大会像快进 |
| H3 档位 | 采纳 Gemini：合并为两档 | 标准升到 60fps 后与"流畅"档重复 |
| H4 亚格平移 | 采纳 Gemini：蒙版按亚格小数平移 | 只让柔光层连续，格子层仍会整格硬跳，两层还会脱节 |
| 未仲裁 | — | 三轮内全部达成一致，没有请 Codex 裁判 |
